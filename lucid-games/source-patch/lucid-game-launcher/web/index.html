런처 다운로드

운영체제에 맞는 런처를 내려받으세요. 데스크톱은 ZIP을 풀고 런처를 실행하세요. 런처에서 원하는 게임의 Download를 누르면 이후에는 오프라인으로 플레이하고 저장할 수 있습니다.

이 언어로 모바일 앱 열기
iPhone · iPad에 IPA 설치하는 방법

개인 서명용 IPA를 내려받으면 Mac 또는 Windows에서 AltServer로 기기에 AltStore Classic을 구성하세요. iPhone이나 iPad의 파일 앱에 IPA를 저장한 뒤 AltStore의 My Apps에서 +를 누르고 해당 파일을 선택해 본인 Apple 계정으로 서명합니다. 무료 계정은 서명 만료 전에 갱신해야 합니다. 기기가 요청하면 설정 → 개인정보 보호 및 보안 → 개발자 모드를 켜세요.

등록 기기용으로 서명된 IPA는 배포 프로파일에 등록한 기기에 Apple Configurator로 추가할 수 있습니다. 소스에서 직접 실행할 때는 Mac의 Xcode에서 Runner 타깃의 개발 팀과 연결한 기기를 선택해 Run을 누르세요.

AltStore Classic 안내 ↗ · Apple 등록 기기 배포 안내 ↗

Chrome은 설정 → 시스템, Edge는 설정 → 시스템 및 성능에서 ‘가능한 경우 그래픽 가속 사용’을 켜고 브라우저를 다시 시작하세요. Firefox는 설정 → 일반 → 성능에서 권장 설정을 해제하고 하드웨어 가속을 켭니다. Chrome의 chrome://gpu에서 WebGL 상태를 확인할 수 있습니다.
