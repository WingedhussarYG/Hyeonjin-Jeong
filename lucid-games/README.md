# Lucid Games

[Play in your browser or download the launcher](https://lucid-game-launcher.maxfaine.chatgpt.site/) · [Strategy wiki](https://two-worlds-wiki.maxfaine.chatgpt.site/) · [Collection releases](https://github.com/WingedhussarYG/Hyeonjin-Jeong/releases)

Choose Korean, English, Spanish, Japanese, Simplified Chinese, German or French in the launcher. The web launcher starts in a supported browser language. Each game's own language menu remains available.

## Play

- **Browser:** Open the launcher, sign in with ChatGPT, choose a game and select a mode where offered. Use the launcher's save controls to transfer progress between the web and a local device.
- **Windows, macOS or Linux:** Download the portable launcher for your operating system and CPU, extract the whole ZIP, and open the launcher. Choose **Download** beside a game. Once its content is on the device, play and save offline.
- **Offline desktop collection:** Extract the complete collection ZIP. Inside the folder for your OS, extract the launcher ZIP **directly into that folder**. Leave the adjacent `Lucid Content` folder in place. Open the launcher and choose **Download** for the games you want to copy from the collection.
- **Android and iOS:** Use the mobile downloads on the official launcher. The two real-time strategy games require a desktop. A personal-signing IPA requires signing before installation. The web launcher's iOS guide explains the steps.
- **Developers:** Download the standalone development source from the release. Run `python3 Lucid-Games-Launcher-Source.zip --verify`, then `python3 Lucid-Games-Launcher-Source.zip --out lucid-development`. The archive includes source, assets, pinned build inputs and handover instructions. The unfinished World of Warcraft prototype is outside this collection.
